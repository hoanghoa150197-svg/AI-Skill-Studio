# Editorial Workspace — V1.5

Mode: Operate (Impeccable). A working skill library and editor, not a marketing page.

Visual world: ink-blue navigation, warm paper surfaces, terracotta action accent. Signature: a grouped, labeled navigation rail and a paper-like editing canvas with a typeset document heading. Georgia for page headings; system sans for controls; monospace only for technical content. Dark and light themes keep the same hierarchy. Four-pixel spacing rhythm; restrained borders, no decorative gradients or glass. Auth uses a two-region layout, with existing form IDs and recovery behavior preserved. Narrow screens use compact navigation and stacked editor panes.

Applied references: SKILL.md, mode-operate, new-work-world, craft-floor, layout, polish (manual implementation). No Impeccable launcher or external design engine used. No external font dependency. No changes to DB, cloud sync, skill schema, imports, exports, validation, or application event handlers. app.js changes limited to render markup and authored SVG paths. Cache version updated for deployment.
